SCANNER_API bool TL_Scanner_StartAutoScan ( const TL_ScannerHandle  scanner,
const TL_ScanMode  mode,
const int  requiredFingers,
const int  contentAnalysesToDisable 
)

Starts to asynchronously capture images with preview.

Delivers the final image when image quality and requirements of the given mode are sufficient. Each preview image is delivered to a user-defined callback (if earlier registered with TL_Scanner_RegisterCallbackPreviewImage()). The final scan image is delivered to a user-defined callback (if earlier registered with TL_Scanner_RegisterCallbackScanImageAvailable()).

Note
These callbacks will be called from a different thread, so only perform thread-safe operations in the callbacks
Requires both TL_Scanner_ModeCapabilities::TL_IS_MODE_SUPPORTED and TL_Scanner_ModeCapabilities::TL_SUPPORTS_AUTO_SCAN to be true!
Do not call while capturing preview images!
Parameters
scannera valid handle to a scanner
modescan mode
requiredFingersa bit field of required fingers. Finger positions are defined in TL_FingerPositions.
contentAnalysesToDisablespecifies the image content analyses to disable. See TL_ImageContentAnalysis. Don't combine TL_ANALYSIS_NONE or TL_ANALYSIS_ALL with any others.
Returns
true if succeeded. Otherwise use TL_GetLastError() for more information:
