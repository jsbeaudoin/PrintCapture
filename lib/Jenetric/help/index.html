API Concepts

Structure

The API is composed of several parts, each of which is specified in a corresponding header file, containing the relevant definitions and functions of the API:

  • TouchLabApi.h: Top-Level. This provides the definitions and functions required to initialize the API and gets handles to internal objects. As such it will generally be required (first) by every client. Before using any API function a call to TL_Initialize() is needed. Definitions and functions of the TOUCHLAB SDK's top-level API.
  • ErrorApi.h: Error handling.
  • ScannerApi.h: Scanner handling.
  • ImageApi.h: Image handling.
  • TouchDisplayApi.h: TouchDisplay handling.
  • SignatureApi.h: Signature handling.
  • LicenseApi.h: License handling.
  • GuidanceApi.h: Guidance handling.
  • SegmentationApi.h: Finger segmentation.
  • EvaluationApi.h: Image evaluation.

The top-level API is the TouchLabApi which provides functions to initialize the API and gets handles to internal objects.

Note
Before using any API function a call to TL_Initialize() is needed.

Error handling

Each function returns false if an error occurs, and otherwise true. To get more information about an error call TL_GetLastError(). In the case that the API has not been initialized properly all functions return false and TL_GetLastError() returns TL_LOGIC error. Each function that succeeds sets the last error code to TL_NO_ERROR (and to the specific error code in the case that they fail).

Usage

A minimum workflow for capturing a single image (without preview) can be implemented as follows:

  1. Always call TL_Initialize() first, to initialize the Api and start monitoring scanners.
  2. Call TL_GetScannerList() to get a list of the serial numbers of the currently connected scanners.
  3. Call TL_FreeScannerList() to release the memory allocated by the call to TL_GetScannerList().
  4. Call TL_OpenScanner() to enable access to a particular scanner.
  5. Call TL_RegisterCallbackScannerListChanged() to register a function to be called when the list of scanners changes, due to one or more scanners being plugged in/out.
  6. Call TL_Scanner_RegisterCallbackScanImageAvailable() to register a callback function which receives the scanned image.
  7. Call TL_Scanner_StartScan() to trigger the acquisition of the scan, in a particular Scan Mode.
  8. Call TL_CloseScanner() to release all resources associated with the scanner.
  9. Before exiting your application, call TL_Finalize() to clean up.
