typedef void(* TL_CallbackGuidanceImageAvailable) (void *context, TL_ImageHandle image, TL_GuidanceDisplayPart displayPart, float time)

A user-defined function to be called after a new guidance image is available.

Every new listener needs one of these callback functions.

Parameters
contexta user-defined context as given on callback registration
imagea valid handle to current guidance image, gets invalid when leaving the callback function
displayPartis the display part for which the new image was rendered. That can also be TL_DISPLAYPART_ALL, then the whole display (all parts together) is meant.
timeis current animation time for the available image. While user is being guided, every available image is part of an animation at a time.

Enumeration Type Documentation

enum TL_GuidanceDisplayPartType

Defines the type of a display part. Every display part has an intended meaning, this defines that meaning.

Enumerator
TL_DISPLAYPARTTYPE_SYSTEMSTATUS 

This display part type is intended to give the user status information about the system itself (not for capture state).

TL_DISPLAYPARTTYPE_STATUS 

This display part type is intended to give the user status information about the current capture process.

TL_DISPLAYPARTTYPE_GUIDANCE 

This display part type is intended to guide the user with information about the current capture process. For LIVETOUCH quattro this is the top area.

TL_DISPLAYPARTTYPE_SENSOR 

This display part type is intended to give the user information about the positions to put the finger(s) on the sensor. For LIVETOUCH quattro this is the bottom area.

GUIDANCE_API bool TL_Guidance_RegisterListenerImageAvailable ( const TL_ScannerHandle  scanner,
int  requestedWidth,
int  requestedHeight,
TL_GuidanceDisplayPart  displayPartFilter,
TL_CallbackGuidanceImageAvailable  callback,
void *  context,
TL_GuidanceListenerImageAvailableHandle *  handle 
)

Registers a new listener at the user guidance of the given scanner.

There are multiple listeners possible for one scanner, contrary to the "callback"-concept. For example, you can register multiple listeners to get user guidance rendered in different image sizes, see "requestedWidth" and "requestedHeight".

Parameters
scannera valid handle to a scanner
requestedWidththe requested width for the guidance images. User guidance will render new images in that size. Can be "0", then requestedHeight is not allowed to be "0", width is automatically calculated according to aspect ratio.
requestedHeightthe requested height for the guidance images. User guidance will render new images in that size. Can be "0", then requestedWidth is not allowed to be "0", height is automatically calculated according to aspect ratio.
displayPartFilterthe display part you want to get information in the callback for. If a special filter is given, the callback will only be fired, if new guidance image matches the display part defined in that filter. TL_DISPLAYPART_ALL can also be used, then the callback will be fired only for the whole screen (all parts drawn together).
callbackthe callback to be fired in case of a new guidance image was rendered.
contexta user-defined context, this is given to the callback if fired.
[out]handlea pointer to receive the handle of the new created listener, is not allowed to be null.
Returns
true if succeeded. Otherwise use TL_GetLastError() for more information:
TL_INVALID_ARGUMENT if invalid scanner handle was given
TL_INVALID_ARGUMENT if null was given for handle parameter
TL_LOGIC if TL_Initialize() not called
