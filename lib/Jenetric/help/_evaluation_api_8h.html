Returns the bounding box of a finger given by index.

Parameters
evala valid scan image evaluation handle to check on
indexindex of finger (The leftmost finger as seen by user when looking down on scanner having index 0 etc.)
[out]lefta pointer receiving the bounding box's left column (must not be null)
[out]topa pointer receiving the bounding box's top row (must not be null)
[out]widtha pointer receiving the segment's width (must not be null)
[out]heighta pointer receiving the segment's height (must not be null)
Returns
TL_INVALID_ARGUMENT if invalid handle was given as eval parameter
TL_OUT_OF_RANGE if index is out of range
TL_INVALID_ARGUMENT if null was given for left, top, width or height parameter
TL_LOGIC if TL_Initialize() not called
