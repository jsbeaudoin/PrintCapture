TL_ROTATED_HAND_COUNTERCLOCKWISE 

hand or finger or single thumb was counterclockwise rotated and needs to be rotated clockwise

TL_ROTATED_HAND_CLOCKWISE 

hand or finger or single thumb was clockwise rotated and needs to be rotated counterclockwise

any of the 2 thumbs were rotated and need correction

TL_ROTATED_TWO_INDEX_FINGERS

TL_HAND_ON_BORDER_TOP

TL_HAND_ON_BORDER_LEFT

IMAGE_API bool TL_GrayscaleImage_GetData ( const TL_GrayscaleImageHandle  image,
unsigned char **  data 
)

Gets access to the pixel data of a given image.

Each gray-scale image allocates width*height bytes (1 byte per pixel). The pixel data is continuously stored from top to bottom row (no fill bytes between successive rows).

Note
The pixel data can be accessed only as long as its associated image handle is valid.
Parameters
imagea valid handle to an image
[out]dataa pointer receiving a temp. pointer to the image's pixel data (must not be null)
Returns
true if succeeded. Otherwise use TL_GetLastError() for more information:
TL_INVALID_ARGUMENT if invalid image handle was given
TL_INVALID_ARGUMENT if null was given for data parameter
TL_LOGIC if TL_Initialize() not called
