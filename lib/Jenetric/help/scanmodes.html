Scan Modes

Scan Mode

A Scan Mode encapsulates several pieces of information about how exactly a scan is to be performed.

  • Whether the scan is of a finger or a document.
  • Whether a finger scan should be rolled or flat.
  • What user guidance (eg images and animations) the scanner displays for the user.
Note
Functions like TL_Scanner_StartScan() accept both a TL_ScanMode parameter (eg TL_PLAIN_4_FINGERS_RIGHT ) as well as a TL_FingersSet parameter (eg TL_RIGHT_INDEX_FINGER | TL_RIGHT_MIDDLE_FINGER ).

Normally, these should correspond exactly ie. the user should place exactly those fingers/thumbs on the scanner that the user guidance suggests, or the scan will not succeed. It is possible however, to use the requiredFingers parameter to allow a scan to proceed successfully even in the case where the user places less than those fingers/thumbs on the scanner. This might be necessary eg. if the user is missing one of those fingers/thumbs. Specifying anything other that exactly the same fingers/thumbs as the scan mode or a subset thereof makes no sense and should be avoided.
